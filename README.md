# 📱 HandyPutz – Testversion

**HandyPutz** räumt dein Android-Handy auf: doppelte Dateien, Downloads sortieren, Datenmüll, Apps in Ordner, eigener Startbildschirm, WLAN-Passwörter, Akku & Laden, Handy-Tuning – mit Google-KI.

## ⬇️ Herunterladen

👉 **[HandyPutz.apk herunterladen](https://github.com/tinoknopp-rgb/HandyPutz-Updates/releases/latest/download/HandyPutz.apk)**

(immer die neueste Version)

## 🛠 Installieren

1. Link oben auf dem Handy antippen → APK wird geladen.
2. Datei öffnen → **Installieren**. Falls gefragt: „Unbekannte Apps installieren“ erlauben.
3. Blockiert **Google Play Protect** die Installation: Play Store → Profilbild → **Play Protect** → ⚙ → „Apps mit Play Protect scannen“ **kurz ausschalten**, installieren, **danach wieder einschalten**.
4. HandyPutz öffnen → „Zugriff auf alle Dateien“ erlauben.

## 🔄 Updates

Neue Versionen meldet die App selbst beim Start: **„Update verfügbar → Jetzt aktualisieren“**.

## 🤖 KI-Funktionen (optional)

Kostenlosen Schlüssel holen: https://aistudio.google.com/apikey → in HandyPutz unter **„Überwachung & KI-Schlüssel“** eintragen.
